Windows & Mac: Clash Verge Rev 保姆级配置教程

Clash Verge Rev 是目前开源社区公认最优秀的 Clash 客户端衍生版。它采用现代化 Tauri 框架编写，内存占用极小，完美支持 VLESS、Shadowsocks 等最新协议。

📥 步骤 1：下载与安装

前往官方开源 Releases 页面下载对应安装包：
- Windows 电脑下载 Clash.Verge_x64-setup.exe
- Mac 电脑根据处理器类型选择 aarch64.dmg (M芯片) 或 x64.dmg (Intel芯片)。

🔗 步骤 2：导入机场订阅链接
  1. 登录你的梯子官网用户中心（如 光速云 或 飞猫云）。
  2. 点击“一键导入 Clash”；或者点击“复制订阅地址”。
  3. 打开 Clash Verge Rev，点击左侧菜单栏的 “订阅 (Profiles)”。
  4. 在上方输入框中粘贴刚刚复制的订阅 URL，点击 “保存 (Save)”。
  5. 右键点击刚刚下载成功的配置，选择“选中 (Use)”。
🚀 步骤 3：开启系统代理与选择节点

1. 点击左侧 “设置 (Settings)”，勾选打开 “系统代理 (System Proxy)”。
2. 点击左侧 “代理 (Proxies)”，确保顶部模式为 “规则 (Rule)”。
3. 在节点列表中点击延迟测速，选择一个低延迟节点（如香港、日本、新加坡或美国），即可正常访问 Google 与 YouTube！

iOS 苹果手机: Shadowrocket (小火箭) 使用指南

由于苹果 App Store 政策，Shadowrocket 需使用非中国大陆的 Apple ID（如美区、港区 Apple ID）在 App Store 购买下载（售价约 $2.99）。

  • 一键导入：用 Safari 浏览器登录机场后台，点击“一键导入 Shadowrocket”，小火箭会自动弹窗并添加所有节点。
  • 手动添加：如果无法自动唤起，复制机场提供的订阅链接，打开小火箭右上角 “+” 号，类型选择 “Subscribe”，在 URL 中粘贴链接并保存。
  • 开启连接：在小火箭首页全局路由选择 “配置 (Config)”，选中节点后开启顶部的总开关，初次使用允许添加 VPN 配置即可。

Android 安卓手机: Clash Meta for Android 教程

安卓用户推荐使用开源免费的 Clash Meta for Android (CMFA)：

  1. 安装 APK 后打开应用，点击 “配置” -> 新建配置 -> 从 URL 导入。
  2. 填入机场订阅链接并点击右上角保存。
  3. 返回首页点击 “启动”，在“代理”页面选择心仪的节点即可。
  4. 如遇打游戏或部分应用无法联网，可在设置中开启 “绕过应用模式”。

新一代全能核心：Sing-box 极速上手

Sing-box 是当下最受瞩目的全功能代理平台，支持最新的 Hysteria 2、TUIC v5、ShadowTLS 等高性能 UDP 穿透协议。如果你的机场提供了 Sing-box 订阅格式，直接在 Sing-box 客户端中添加该 JSON 订阅即可享受更极致的性能。

核心概念科普：规则分流 vs 全局代理 vs TUN虚拟网卡

模式类型 工作原理 适用场景与优缺点
规则分流 (Rule) 根据域名和 IP 地址库自动判断走直连还是走代理 日常推荐：国内网站飞快，国外网站加速，互不影响
全局代理 (Global) 所有流量一律强制走代理服务器 仅适合国外网站打不开时的应急调试，不建议日常常驻
TUN 虚拟网卡 在操作系统创建虚拟网卡接管全部网络请求 高阶推荐：完美接管 Git Clone、命令行终端、游戏外服
